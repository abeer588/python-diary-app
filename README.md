# Python Diary Application

A Python command-line application for creating and viewing dated diary entries.

## Features
- Choose which text file to use as the diary.
- Save each dated entry on a separate line.
- Filter and print entries by date.
- Load another diary file while the program is running.

## Requirements
Python 3. No additional packages are required.

## Running the Application
1. Download the repository and extract the ZIP file.
2. Open a terminal in the extracted folder.
3. Run:

   ```bash
   python main.py
   ```

   On Windows, you can also run:

   ```bash
   py main.py
   ```

4. Enter a diary filename, such as diary.txt.
5. Use the numbered menu to add entries, search by date, switch files, or exit.

Enter dates consistently in YYYY-MM-DD format.

## Project Files
- main.py: Application entry point and interactive menu.
- diary.py: Functions for diary file creation, saving, and date filtering.
- diary.txt and diary1.txt: Sample diary files.
